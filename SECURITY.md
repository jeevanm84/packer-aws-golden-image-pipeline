# Security policy

## Report privately

Do not open a public issue for a suspected vulnerability. Use **Security → Report a vulnerability** in this repository to contact [@jeevanm84](https://github.com/jeevanm84) privately.

Include the affected file or workflow, reproduction steps, possible impact, and suggested mitigation. Remove all live credentials and account identifiers.

## Educational scope

This repository is designed for sandbox learning accounts. Its example IAM policy, public-subnet smoke test, and temporary SSH path are intentionally understandable and are not universal production controls. Review every policy and network path before adapting it to a real organization.
